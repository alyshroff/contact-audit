Contact Audit

This app talks straight to your Google account from your phone. Nothing is stored anywhere but on this device. To let it in, Google needs you to register it once — about five minutes, then never again.

Your OAuth Client ID

Ends in .apps.googleusercontent.com

How to get that ID
  1. Open Google Cloud Console and create a project. Name it anything.
  2. Go to APIs & Services → Library, search People API, press Enable.
  3. Go to OAuth consent screen. Pick External, fill in the app name and your own email, and save. On the Audience step, add your own Google address under Test users. Leave it in Testing — you never need to publish or get verified.
  4. Go to Credentials → Create credentials → OAuth client ID. Type: Web application.
  5. Under Authorized JavaScript origins, add the exact address you'll open this page at — for GitHub Pages that's https://yourname.github.io (no path, no trailing slash). Leave redirect URIs empty.
  6. Create it, copy the Client ID, paste it above.
Where to host this file
Google only trusts https:// origins, so opening the file from your camera roll won't work. Easiest free option: make a public GitHub repo, upload this file renamed to index.html, then turn on Settings → Pages from the main branch. You'll get a https://yourname.github.io/reponame/ address in a minute or two. Open it in Safari or Chrome on your phone and use Add to Home Screen — it then runs full-screen like a normal app.
What it can do to your contacts
Nothing until you press Push, and it shows you the full list first. Google Contacts has no true archive, so Archive applies a label called Archived — reversible, and it keeps the contact and their history. Delete is a separate, rarely-needed button and is permanent after 30 days in Google's trash. Notes are written to the contact's Notes field, replacing what was there.
